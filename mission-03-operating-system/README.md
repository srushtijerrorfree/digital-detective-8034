TASK 3.3:
-->Absolute path: The complete location of a file or folder starting from the root directory.

Relative path: The location of a file or folder in relation to the current working directory.

Example:
- Absolute path: /Users/[redacted]/digital-detective-1234/mission-03-operating-system/

3. Commands / tools used
- uname -a – Displays system information.
- whoami – Displays the current account username.
- df -h – Displays disk usage in human-readable format.
- top – Displays running system processes.
- ps – Displays process information.
- pwd – Displays the current directory.
- ls -l – Displays detailed file information and permissions.

4. My understanding
An operating system acts as an interface between the user, applications and computer hardware. It manages processes, memory, files, devices and security. Processes represent running programs, while permissions control what users can do with files. Absolute and relative paths help locate files in the computer's directory structure.

5. My Understanding

In this misssion, I have understood that an operating system acts as a bridge between computer hardware, applications and the user.

It manages processes so that multiple programs can run, manages memory so applications can work properly, and handles files, devices and permissions.

I also learned that a process is an active running program and that its PID helps the operating system identify it.

Absolute and relative paths are two different ways of locating files. File permissions determine whether a user can read, modify or execute a file.
