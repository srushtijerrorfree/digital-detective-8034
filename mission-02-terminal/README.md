TASK 2.1:
-->Operation |Command |Purpose
1. Current directory |pwd |Displays the current location
2. List files |ls |Lists files and folders
3. Detailed listing |ls -l |Shows detailed file information
4. Change directory |cd foldername |Moves into a directory
5. Parent directory |cd .. |Moves one level up
6. Create directory |mkdir practice |Creates a new folder
7. Create empty file |touch file.txt |Creates an empty file
8. Copy file |cp file.txt copy.txt |Creates a copy
9. Move / rename |mv copy.txt new.txt |Moves or renames a file
10. Display contents |cat file.txt |Displays file contents


TASK 2.2:
-->
1. Replacing file contents overwrites existing content, while appending adds new content at the end.

2. Copying creates another version of a file, while moving changes its location.

3. pwd displays the current working directory.

4. ls helps identify files and folders in a directory.


TASK 2.3:
1. ls -l displays detailed directory information.

2. ls -la also includes hidden files.

3. ls -lah displays hidden files and human-readable file sizes.

4. ls -l | head displays only the first few lines of the detailed listing.
