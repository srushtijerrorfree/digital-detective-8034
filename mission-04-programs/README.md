1. When execution happens	|Translates the program before execution	|Executes instructions at runtime
2. Typical output	|Often produces an executable or other translated form	|Often executes without creating a separate native executable
3. Example	|C compiler (GCC)	|Python interpreter
4. Advantage	|Compiled programs can execute efficiently	|Convenient for testing and interactive execution

-->Explanation:

A compiler translates source code into another form before the program is executed. An interpreter reads and executes program instructions at runtime. Compilers commonly produce executable machine code, whereas interpreters execute instructions through a runtime environment. Both approaches help computers execute programs.
